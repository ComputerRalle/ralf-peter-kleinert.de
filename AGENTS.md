# Projektanweisungen für KI-Assistenten

## Lokale Arbeit und Veröffentlichung

- Dieses Projekt wird über GitHub Pages als Live-Website unter https://ralf-peter-kleinert.de veröffentlicht.
- Bearbeite die Projektdateien ausschließlich lokal. Veröffentliche Änderungen nicht selbst.
- Der Benutzer führt alle Pushes selbst über Git Bash aus. Führe daher keinen `git push` aus und veranlasse auch keinen Push über andere Werkzeuge oder Dienste.
- Starte keine Deployments oder sonstigen Veröffentlichungen. Die Veröffentlichung übernimmt der Benutzer.
